Bulk Import Products

📋 Import Instructions

  • Upload an Excel file (.xlsx) with product data
  • Required columns: Category, Name, SKU, Price
  • Rows with Is_live = Yes will be skipped
  • Duplicate SKUs will be skipped
  • Missing Slug will be auto-generated from the product name
  • Description and images should be added manually after import

📊 Excel Column Reference

Category *
Category name (required). New categories will be auto-created.
Name *
Product name (required).
Slug
URL-friendly name. Auto-generated if empty.
SKU *
Product SKU (required). JFP- prefix added if missing.
HSN Code
HSN code (numbers only).
Price *
Base price before GST (required).
Compare At Price
Strike-through price (shown as sale badge if higher than price).
GST Percentage
Tax percentage (default: 18.00).
Stock
Initial stock quantity (default: 0).
Height CM
Height in centimeters (optional).
Width CM
Width in centimeters (optional).
Weight G
Weight in grams (optional).
Is Active
Yes/No or True/False (default: True).
Is Bestseller
Yes/No or True/False (default: False).
Is Customizable
Yes/No or True/False (default: False).
Is Returnable
Yes/No or True/False (default: True).
Bulk Threshold
Quantity above which requires quote (optional).
Min Qty
Minimum order quantity (default: 1).
Is_live
Set to "Yes" to skip this row.
Notes
Internal notes (not displayed to customers).
